## 导出问题与修复

最初通过浏览器 Blob URL 下载触发了下载事件，但文件检查发现空文件。进一步验证发现，原录制流程没有产生有效数据；内置浏览器下载桥接的落盘事件也不能作为文件内容验证。

修复措施：把录制画布挂载为可见预演，优先使用 VP8，主动请求视频帧；对空结果阻止保存并显示明确原因；导出文件通过本地服务持久保存后提供 HTTP 地址。文字类导出也使用同一落盘路径。

修复后的实际证据：

- 静音 WebM 保存至 `data/exports/ae4666ae-5391-47c8-a3ce-7e8ecf3d1279.webm`，4,330,136 字节，文件头为 WebM/EBML。
- 浏览器视频播放器 `readyState = 4`，解码尺寸 1280×720，无视频错误。
- 分镜 CSV 保存至 `data/exports/3fb58dc0-d1a3-466a-8fd2-275a0c2b7028.csv`，4,517 字节，含 UTF-8 BOM 和镜头表内容。
- 导出文件本地地址的字节完整性由 HTTP 集成测试验证。内置浏览器下载桥接返回的宿主文件路径未被用作成功依据。

预演录制按镜头清单的 30 秒实时进行；MediaRecorder 的 WebM 容器可能不提供有限 duration 元数据，后续 FFmpeg 渲染应补齐索引与精确时长。预演没有音轨，也没有模型生成的动态动作。
