# Nexus Studio / AIGC NexusAgent

从创意到专业分镜、素材管理与多平台交付的中文导演工作台。代码在用户指定的 `YiQuanYuan/AIGC_NexusAgent` 仓库工作目录中实现。

## 启动

需要 Node.js 22 或更高版本，无第三方运行依赖，无需安装 npm 包。

```sh
npm run dev
# 或
node server/index.mjs
```

打开 <http://127.0.0.1:4317>。`npm run start` 启动普通服务。默认只监听本机。

如果当前电脑的 Node 未加入 PATH，可使用 Codex 内置运行时：

```sh
/Users/yuanyiran/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server/index.mjs
```

## 初版已经实现

- 创作工作台：五阶段流程，示例短片《最后一班月球列车》。
- 项目创建：输入创意、类型、时长、画幅，生成明确标注的本地结构模板。
- 剧本与视觉圣经：编辑故事结构、角色、场景、风格、色彩与负面约束。
- 分镜编辑：景别、焦段、运镜、时长、光线、行动、台词、声音、连续性、提示词；关联图片、确认镜头、拖动排序。
- 素材库：本地上传图片、视频、音频；分类、标签、来源、镜头引用、使用权确认、下载。
- 分镜预演：播放、暂停、拖动进度；导出静态分镜的静音 WebM 预演，按项目画幅生成。
- 工程交付：UTF-8 CSV 专业镜头表、对白 SRT、JSON 工程与交付清单。
- 发布中心：三平台能力说明、母版选择、使用权和 AI 声明检查、排期记录、待接入/待人工交付状态、手动登记对应平台作品链接、取消任务。
- 可选 LibTV：服务端提交官方 Agent-IM 创作会话、手动查询原始消息、跳转画布。未配置密钥时不会伪造生成结果。
- 数据持久化：`data/studio.json` 与 `data/uploads/`；队列串行、临时文件原子替换。本机单服务实例使用。
- 响应式布局、键盘焦点、弹窗焦点限制和减少动态效果偏好支持。

## 使用路线

1. 先浏览示例的分镜卡片，打开镜头编辑器。
2. 新建自己的项目，在「创意与剧本」完善故事。
3. 在「角色与场景」写固定设定，上传自己的参考素材。
4. 编辑各镜头的行动、声音、时长和提示词，关联素材，播放节奏预演。
5. 在剪辑工具中完成精剪，上传真实视频母版，在素材详情中确认使用权。
6. 在「成片与声音」选择母版并确认 AI 声明。
7. 创建平台交付任务；实际平台发布后可登记作品链接。

## 配置 LibTV

```sh
cp .env.example .env
# 在 .env 中填写 LIBTV_ACCESS_KEY，勿提交到 Git。
node --env-file=.env server/index.mjs
```

然后打开分镜编辑器，点击「提交 LibTV」。提交前会保存镜头信息，并携带角色和视觉设定。该操作调用真实服务并可能消耗供应商配额。

接口依据：[LibTV 官方 Agent-IM 仓库](https://github.com/libtv-labs/libtv-skills)。真实调用尚未使用付费密钥验证；本地已经验证未配置时明确返回 409。返回消息未自动下载入库；在「模型与集成」手动查询并打开画布。

## 当前边界

- 本地草稿来自故事结构规则，不是大模型理解创意后生成的完整剧本。
- 示例图片是仓库内原创 SVG 示意图，不是 AI 生成的电影画面。导出的预演是静态画面、轻微推近与字幕，无声音，不是 AI 动态视频。
- 未实现音轨混合、视频探测、FFmpeg 拼接、MP4 精剪导出、自动生成封面。
- 上传采用 JSON/base64，单文件 20MB；按声明 MIME 和扩展名入库，尚未做文件头检测、病毒扫描和 ffprobe 真实性探测。不要作为公网媒体服务部署。
- 未连接任何媒体账号；抖音 OAuth 与发布适配器尚未实现。小红书与红果按真实能力提供人工交付记录，不模拟自动发布。
- 排期只保留计划时间，不包含执行调度器。手动登记状态仅代表用户提供链接，未经平台接口核实。
- 版本目前固定 v1，历史版本、父素材血缘、软删除、项目重命名、多人权限、费用台账留待下一阶段。
- 初版是本机、单用户、单进程应用；没有登录认证。请维持 loopback 监听，备份 `data/`。
